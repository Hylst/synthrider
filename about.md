# À propos de SynthRider

## Le jeu

SynthRider est un jeu de course rythmique pseudo-3D inspiré de l'esthétique synthwave et de la demoscene. Le joueur pilote un vaisseau sur une piste perspective à 5 voies, au rythme de 120 BPM.

## L'univers visuel

- **Palette** : cyan, magenta/fuchsia, jaune sur fond violet foncé
- **Ambiance** : rétro-futuriste, neon, grille perspective, montagnes au loin
- **Style** : 100% vectoriel (Canvas 2D), aucune image externe
- **Influences** : OutRun, F-Zero, Tron, synthwave, demoscene Atari ST

## La musique

L'audio est entièrement généré en temps réel via l'API Web Audio du navigateur. Pas de fichier MP3 — juste du code qui crée des sons synthwave procéduraux (basses, nappes, percussions, effets).

## Le gameplay

1. **Objectif** : atteindre 2400 mètres sans crash
2. **Gemmes** : à collecter pour augmenter le score et la jauge Synchro
3. **Barrières** : à esquiver (sinon = crash, sauf bouclier/surcharge)
4. **Combo** : chaînez les collectes pour multiplier le score
5. **Synchro** : jauge remplie par les gemmes et esquives → activation Surcharge
6. **Surcharge** : mode invincible temporaire, traverse les barrières
